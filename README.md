# ReadyForge AI – Home Services Template

Complete, ready-to-sell website for plumbing, HVAC, and handyman businesses.

## What’s included
- Fully responsive HTML/CSS/JS
- Conversion-focused layout (hero, services, social proof, strong CTA)
- Mobile-first design
- Placeholder for AI assistant widget
- Clean, professional branding (easy to recolor)

## How to use / sell
1. Customize business name, phone, colors, and services
2. Host free on GitHub Pages or any free static host
3. Connect a free form handler (Formspree free tier) or AI chatbot
4. Deliver the files or live link to the customer

## Files
- index.html – main page
- styles.css – all styling
- script.js – smooth scroll + AI placeholder

Built with zero paid tools. Ready for ReadyForge AI sales.
